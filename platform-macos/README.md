# platform-macos

Projeto Swift nativo (AppKit + Accessibility API) do Etherbit Tiling para macOS.

> **Nota de arquitetura:** os arquivos aqui ficam visíveis e editáveis dentro do
> Dev Container (como texto), mas o **build deve ser feito no host macOS local**,
> pois o SDK da Apple (Xcode/AppKit) não está disponível no container Linux.
