A essência: Ether + Bit

O nome é a fusão cirúrgica de dois conceitos — física e computação — que definem a alma do algoritmo. Juntos, criam uma experiência única de produtividade, independente do sistema operacional.

Ether — o preenchimento do vazio

Na física clássica, o Éter era a substância invisível que preenchia todo o espaço. Aqui, o Ether é o preenchimento matemático de pixels: um tecido invisível que organiza as janelas em blocos para que cada pixel da tela seja aproveitado de ponta a ponta, sem buracos e sem sobreposições.

Bit — a gravidade da órbita

O sufixo Bit herda a mecânica de Orbit (Órbita): o equilíbrio perfeito onde as janelas encontram suas posições ideais sozinhas, guiadas pela gravidade computacional do sistema. E celebra o bit como unidade da computação — foco em performance pura e nativa.

Tiling Dinâmico

Abriu um terminal, um editor ou o navegador? A janela vai para a órbita correta na hora. Sem mouse.

Ether Flow

Nativo e resiliente

Reportar Problemas & Diagnóstico

Encontrou um bug? Gere um arquivo de log limpo com um único comando e anexe ao seu reporte. Escolha o bloco do seu ambiente e o cenário que se aplica.

GNOME Shell (Mutter)

Por tempo · última 1 hora

Filtra a saída da extensão do GNOME na última hora e unifica a telemetria do Core (se existir). Salva na sua pasta Downloads.

{ journalctl --user -o cat --since "1 hour ago" /usr/bin/gnome-shell 2>/dev/null | grep -iE 'etherbit|JS ERROR|JS WARNING|GDBus'; [ -f ~/.local/share/etherbit-tiling/debug.log ] && printf '\n--- core debug.log ---\n' && cat ~/.local/share/etherbit-tiling/debug.log; } > ~/Downloads/etherbit-gnome-$(date +%Y%m%d-%H%M%S).txt

Por sessão · boot atual

Mesmos filtros, mas todo o histórico desde a última inicialização do sistema. Use quando o problema ocorreu antes nesta sessão.

{ journalctl --user -o cat -b 0 /usr/bin/gnome-shell 2>/dev/null | grep -iE 'etherbit|JS ERROR|JS WARNING|GDBus'; [ -f ~/.local/share/etherbit-tiling/debug.log ] && printf '\n--- core debug.log ---\n' && cat ~/.local/share/etherbit-tiling/debug.log; } > ~/Downloads/etherbit-gnome-$(date +%Y%m%d-%H%M%S).txt

KDE Plasma (KWin)

Por tempo · últimas 2 horas

Isola os logs do KWin e do motor do Etherbit nas últimas duas horas e unifica a telemetria do Core (se existir). Salva na sua pasta Downloads.

{ journalctl --user -o cat --since "2 hours ago" QT_CATEGORY=kwin_scripting 2>/dev/null | grep -iE 'etherbit|tiling'; journalctl --user -o cat --since "2 hours ago" -u etherbit-tiling-daemon.service 2>/dev/null; [ -f ~/.local/share/etherbit-tiling/debug.log ] && printf '\n--- core debug.log ---\n' && cat ~/.local/share/etherbit-tiling/debug.log; } > ~/Downloads/etherbit-kde-$(date +%Y%m%d-%H%M%S).txt

Por sessão · boot atual

Mesmos filtros, mas todo o histórico desde a última inicialização do sistema. Use quando o problema ocorreu antes nesta sessão.

{ journalctl --user -o cat -b 0 QT_CATEGORY=kwin_scripting 2>/dev/null | grep -iE 'etherbit|tiling'; journalctl --user -o cat -b 0 -u etherbit-tiling-daemon.service 2>/dev/null; [ -f ~/.local/share/etherbit-tiling/debug.log ] && printf '\n--- core debug.log ---\n' && cat ~/.local/share/etherbit-tiling/debug.log; } > ~/Downloads/etherbit-kde-$(date +%Y%m%d-%H%M%S).txt

Como enviar o relatório

  1. Abra o terminal do seu sistema operacional.
  2. Copie e execute o comando correspondente ao seu ambiente gráfico e cenário desejado.
  3. Localize o arquivo de log gerado automaticamente na sua pasta Downloads.
  4. Clique em Reportar Bug para abrir uma Issue no nosso repositório e anexe o arquivo extraído.
